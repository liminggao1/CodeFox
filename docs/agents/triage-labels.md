# Triage Labels

工程技能使用五种规范分诊角色。本文件把这些角色映射到本仓库议题追踪器实际使用的标签字符串。

| 规范角色 | 本仓库标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 待维护者评估 |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 描述完整，可交给 agent 实现 |
| `ready-for-human` | `ready-for-human` | 需要人工实现 |
| `wontfix` | `wontfix` | 决定不处理 |

技能提到某个角色时（例如"打上可交给 agent 的分诊标签"），使用本表对应的标签字符串。
