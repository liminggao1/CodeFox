# CodeFox 本地 Web MVP

## Summary

- 增加本地单用户 Web 工作台：React 前端通过 FastAPI 连接一个现有 `InteractiveRuntime`，保留同步执行线程和文件会话存储。
- MVP 验收目标：提交任务并看到流式回复和工具状态；批准或拒绝工具调用；停止当前回合；在页面中列出、新建和恢复会话。
- 采用两个本地开发服务器：FastAPI 绑定 `127.0.0.1:8010`，React/Vite 绑定 `127.0.0.1:5173`，由 Vite 代理 API 和 WebSocket。

## 实现变更

- 在 `src/codefox/frontends/web/` 增加 FastAPI 应用与事件桥接。应用 lifespan 创建并启动唯一的 `InteractiveRuntime`；关闭时调用 `close()`，持续处理事件直到收到 `runtime_closed`。
- 使用单一双向 WebSocket `/api/runtime`。浏览器发送 `submit`、`stop`、`ack`、`approval_decision`；后端返回提交结果、运行时事件、审批请求和操作结果。阻塞式事件读取放在线程中执行，不改造 Agent loop。
- WebSocket 桥接器只有一个事件消费者。浏览器确认处理事件后，后端才调用 [`acknowledge_event()`](D:/01dpan/01project/life/learncc/agent-harness/src/codefox/runtime/interaction.py:264)，再通过 `next_approval()` 交付审批。断线时保留一个未确认事件和未处理审批，重连后重发；同一时间只接受一个 WebSocket 客户端，第二个客户端收到连接忙提示。
- 会话按钮复用现有命令：`/resume` 列表、`/resume <id>` 恢复、`/new` 新建。React 从 `command_result` 展示会话列表，从 `session_changed.records` 恢复记录，不直接读写会话文件。
- 在独立 `frontend/` 建立 React/Vite 页面，提供对话区、输入框、发送/停止按钮、工具审批卡和基础会话选择。流式正文与最终展示记录合并，避免重复显示；桌面和窄屏均可用。
- `pyproject.toml` 增加 Web 可选依赖；增加 `.nvmrc` 固定 Node 主版本为 24，并补充本地启动说明。

## 测试与验收

- 使用离线假模型覆盖 WebSocket 提交、忙碌/无效提交、事件确认顺序、审批放行、停止、断线重连、会话列表/新建/恢复、第二连接拒绝和关闭收尾。

## 假设与边界

- 单个运行时、单个活动浏览器连接；不做多用户隔离、数据库、登录、会话删除、云端部署或权限模式设置。
- WebSocket 断开时运行时继续执行，进程内保留待交付事件；服务器进程退出后不恢复正在执行的回合，只能通过已有会话恢复已保存上下文。
- Python 与 npm 新依赖按项目规范在实施前取得安装许可；WSL 的 `learncc` Python 可通过 `/home/gaogao/miniconda3/envs/learncc/bin/python` 使用。
