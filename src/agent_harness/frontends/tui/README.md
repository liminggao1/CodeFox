# tui：Textual 界面

为共享交互运行时提供终端图形界面。`frontends/cli.py` 的 `tui` 路由启动 `HarnessApp`。

| 文件 | 职责 |
| --- | --- |
| [app.py](app.py) | `HarnessApp`：工作台布局、输入提交、命令候选选择、事件消费、审批呈现、会话选择与退出 |
| [conversation_view.py](conversation_view.py) | 对话控件映射、完整操作组、80 条历史窗口、展开状态、活动正文重建与审批定位 |
| [widgets.py](widgets.py) | CodeFox 品牌栏、可收起会话状态面板、命令候选、对话记录、流式正文、调用外框、内联审批和会话弹窗 |
| [__init__.py](__init__.py) | 标识 TUI 包 |

命令候选来自 [runtime/local_commands.py](../../runtime/local_commands.py)。
界面负责筛选和呈现候选、构造输入；命令是否允许执行及其效果由运行时决定。
事件在 UI 线程展示成功后调用 `acknowledge_event()`，随后领取可交付的审批。
界面通过通道提交审批决定，不直接执行工具。
实时和恢复都消费共享 `ConversationProjection`，控件只呈现投影状态；历史审批只读。
仅挂载最近一段记录，可加载更早记录；前端不读写会话文件。
页面由品牌栏、对话区和底部输入区组成。品牌栏右侧固定三个按钮：会话历史、只读设置和开启新会话（提交 `/new`）。
品牌栏宽屏 1 行；窄屏 2 行，第二行放会话标题和 `[状态]` 入口。
右侧只读会话状态面板默认收起，由对话区顶部行右侧的 `[状态]` 展开，展开后 32 列并带 `[收起]`。
窄屏展开状态面板时对话列让位，面板占满主体宽度，输入区和草稿保持可见。
同次模型调用按关联 ID 分组：调用外框默认收起为一行 `运行中 <本次操作> · 已耗时 Ns`，完整操作原样透传不截断；单击展开后先显示 `已运行的命令` 分组头，再逐条列出 `已运行 <本次操作>`。
用户消息在左侧对话区右对齐，模型回复和事件左对齐，正文使用同一主文字色；Hook、工具和后台事件使用低亮度事件样式。
消息框内不显示“你”“CodeFox”等来源标签，只保留正文；事件框保留来源名。
输入区只有一个主按钮，只有“发送”和“停止”两个文案；Enter 发送，Shift+Enter 换行。输入框上方显示运行时状态（就绪/处理中/关闭中），下方左侧是权限摘要、右侧是模型名、消息数量和字符预算。
会话恢复、删除、`/new` 和设置面板都调用共享运行时，不直接读写会话文件；顶部入口点击后焦点回到输入框，草稿不丢失。
单个事件行用“进行中”，调用外框收起行用“运行中”，两者不混用。
摘要默认可见，详情与过程组分别限制高度；审批保持在组外。底部摘要固定 1 行，窄屏模型名过长时从行尾截断。
临时正文片段按调用和文本块更新，正式消息确认同一正文；失败尝试收起并标明未采用。

共享后端是 [runtime/](../../runtime/README.md)，输入与路由边界见 [frontends/README](../README.md)。
快捷键和使用方式见 [开发笔记](../../../../note/dev-notes.md#textual-交互界面)。
